# dev-lore

开发小技巧 & 小脚本，随用随查。

## 目录

- `subtitle-motion/` — MV 歌词字幕动效：视频 + LRC → 逐字动效成片（10 种风格，ffmpeg/libass）
- `img-tools/` — 图片小工具（webp → png）
- `tag-audio/` — 音频元信息批量写入（FLAC/MP3）
- `vscode_dev_env/` — 各技术栈的 `.vscode` 开箱配置模板
- `reg/` — Windows 注册表小脚本（键位互换、右键菜单等）
- `software_list/` — 本机软件清单导出
- `tips/` — 文字记录的小技巧
- `scripts/` — 可直接用的脚本
