## 〇、换一条视频怎么用（一条命令）

```bash
python render.py --video 新视频.mp4 --lrc 新歌词.lrc --style neon --out 输出.mp4
```

就这一行。画面分辨率自动从视频里读，字号、位置、描边自动按比例换算，不需要改代码。

常用参数：

| 参数 | 作用 |
|---|---|
| `--style` | 风格名，见下表；默认 `neon` |
| `--from / --to` | 只做某一段（秒），按**原曲时间**填，音频视频一起切 |
| `--offset 40` | 视频第 0 秒对应原曲第几秒。整片不用填；**如果视频是从原曲中途剪出来的片段，必须填这个**，否则字幕全错位 |
| `--dim 0.07` | 轻微压暗画面，亮调素材上白色字幕更突出 |
| `--sat 1.14` | 饱和度倍数，配合 `--dim` 用 |
| `--preview 41.6` | 只导某一秒的一帧 PNG，用来快速验位置，不编码 |
| `--crf 19` | 画质，越小越好越大越快 |
| `--keep-ass` | 保留生成的 ASS，方便手动改 |

换歌只需要准备两样：**视频** + **LRC 歌词**（标准 `[mm:ss.xx]歌词` 格式，UTF-8）。

两种时间轴用法：

```bash
# 整片（视频和原曲等长）—— 直接填原曲秒数
python render.py --video MV.mp4 --lrc 歌.lrc --style neon --from 40 --to 60

# 已经剪好的片段（视频开头＝原曲第 40 秒）—— 加 --offset
python render.py --video 片段.mp4 --lrc 歌.lrc --style neon --offset 40 --from 40 --to 60
```

## 一、已实现（10 种，可直接出片）

要单独出 ASS（比如拿去 Aegisub 里改）：

```bash
python karaoke.py --lrc 歌词.lrc --video 视频.mp4 --style all --outdir 输出目录
```

- `--video` 自动探测分辨率；也可以 `--size 1920x1080` 手动指定
- `--style` 可以是单个、逗号分隔多个、或 `all`
- `--from / --to / --shift`：截取时段、时间轴平移
- 输出：`_style_<名字>.ass`

烧录（路径里带中文/冒号时用 `render.py` 更省事）：

```bash
ffmpeg -i "成片.mp4" -vf "ass=filename='路径/_style_neon.ass'" \
       -c:v libx264 -crf 19 -pix_fmt yuv420p -c:a copy 输出.mp4
```

### 怎么看效果

不用一个个烧视频，两种快法：

```bash
# 一张静帧拼图（几秒出图），同一句歌词、同一时刻并排
python preview.py --video 片子.mp4 --lrc 歌词.lrc --at 42 --styles all --cols 5

# 一条对比片（带声音），每段 4 秒首尾相接
python preview.py --video 片子.mp4 --lrc 歌词.lrc --at 42 --styles neon,slam,cine --mode video
```

`--at` 填歌词行的开始时间即可，脚本会自动把取帧点推后 0.9 秒避开淡入。

## 三、毛笔字那条线（已做通，暂搁置）

`brush_render.py` + `brush.py` 是另一条技术路线：**从字体文件里把每个字的轮廓抽成 ASS 矢量绘图（`\p1`）**，绕开 libass 的字体加载。

为什么需要它：**libass 在这台机器上只认铁蒺藜体一个字体**（只有它带 TrueType hinting 表）。志莽行书、马善政毛笔楷全部回退成黑体，试过装系统字体、换 PostScript 名、单目录隔离、fontTools 子集化重写，全无效。根因是这台机器的 fontconfig 配置坏了（`drawtext` 一用就崩 `0xC0000005`）。

矢量路线已验证可行：
- 三种书法字体的字形全部正确绘制，包括狂草
- `\p1` 绘图原点就是 `\pos` 点，与 `\an` 无关
- 缩放、透明度、模糊发光、描边投影、旋转，**所有动画标签都能用在矢量绘图上**

```bash
python brush_render.py --lrc 歌词.lrc --from 40.2 --to 52.5 --shift 40.2
```

已知问题：未唱字的暗红与已唱字对比过强时会像“两套字叠在一起”，需要改成同色相只差透明度（已改到 `alpha=0x82` + 同色 `#E81414`，加 `#FF3030` 发光层，但还没最终定稿）。

字体放在 `fonts/` 下（仓库不带字体文件，来源见 [fonts/README.md](./fonts/README.md)）：
`TiejiliSC-Regular.ttf`、`ZhiMangXing-Regular.ttf`、`Ma Shan Zheng Regular.ttf`。

## 四、通用性：能换哪些视频，还缺什么

### 已经通用的部分

| 项目 | 说明 |
|---|---|
| **任意分辨率** | 用 `--video` 自动读，或用 `--size 1920x1080`。已实测 1080×1920 / 1920×1080 / 720×1280，4K 数值校验通过 |
| **任意视频** | 只要 ffmpeg 能解。有没有音轨都行（有音轨就原样保留，转 aac） |
| **任意歌词** | 标准 LRC。别的格式先转一遍（`[mm:ss.xx]` 行首时间戳） |
| **任意时长** | 190 秒整片和 14 秒片段都验证过 |
| **横竖屏** | 位置按高度比例，字号按「高度」和「宽度」综合。竖屏原样，横屏自动放大字号，巨字自动改每行字数 |

### 分辨率自适应规则

- **位置的缩放系数** = 画高 / 1920。竖屏 y=1440（75% 高）→ 横屏 1080 高时 810，仍是 75%
- **字号的缩放系数** = max(画高/1920, 画宽/1080 × 0.52)。横屏若只按高度缩放，字会瘦得像小字报（占宽只剩 2%）
- **巨字每行字数**：竖屏 5 字，横屏自动放到 8–10 字，否则三行会把 1080 高撑满
- **竖排 vtext 的横向位置**按画宽比例（82%），不按高度

### 换素材时必须注意的三件事

1. **字体只有铁蒺藜体能被 libass 直接加载**（`huge` 风格用它）。`Microsoft YaHei`、`Source Han Sans SC` 是系统字体，任何 Windows 机器都有。`Noto Sans SC` 会被渲染成极细 Thin——`ink` 风格正是要这个效果，但别指望它变粗。
2. **亮画面别用 `ink`**。深墨色细字压在浅色画面上几乎看不见，只在白墙/浅木这类干净背景上成立。
3. **`mirror` 只在暗背景成立**。倒影压在浅色画面上等于没有。

### 还不能自动做的

- **断行**：巨字按字数均分，不管语义。「把痛调成静音让它一直响」会被拆成 6+5，可能断在词中间
- **逐字精度**：现在按字数均分，快段差半拍。真数据在 MFA 的 `words` 层里
- **关键词语义**：`cine` 的橙色关键词是给这首歌写死的（静音/最大声/听不见…），换歌要改 `karaoke.py` 里 `cine` 的 `keywords`

## 五、技术约束（改参数前必看）

1. **字体加载**：只有铁蒺藜体能被 libass 直接加载。`Noto Sans SC` 是可变字体，会被渲染成极细 Thin 且加粗无效——`ink` 风格正是利用这一点做质感，但想用它做粗体就是不行。要粗体用 `Microsoft YaHei` 或 `Source Han Sans SC`。
2. **ASS 颜色是 `&HBBGGRR`**，不是 `&HRRGGBB`。写反了红色会变蓝紫。
3. **`\1c` 是累积标签**，不逐字重置。关键词变色会串到后面整句，必须每字显式写回。
4. **`\pos` 和 `\move` 不能同时出现**，否则位置行为不确定。
5. **`\kf` 是逐字染色本体**，实测扫色确实从左往右推进；但两个颜色明度太接近时肉眼分不出来（尤其压在亮背景上），未唱色必须够深。
6. **ASS 时间戳必须写成 `0:00:03.10`**，写成 `3.10` 会被 libass 静默丢弃整条事件（不报错，只是不显示）。
7. **ffmpeg 截帧时 `-ss` 放 `-i` 前**会导致字幕时间轴错位，画面空白；要嘛用输出端 seek，要嘛先用 `-ss` 切视频再单独烧字幕。
8. **`-ss` 放在 `-i` 前面会把 pts 重置为 0**，截到的其实是"第 0 秒"那一帧，此时字幕还没开始，会误以为渲染失败。截帧预览要用输出端 seek（`-i` 之后）。
9. **`render.py` 里用 `cwd=临时目录` + 相对文件名**，绕开 Windows 路径里 `C:` 冒号被 ffmpeg 当参数分隔符的问题。手写 ffmpeg 命令时路径含中文/冒号容易踩。
10. **逐字节奏目前是按字数均分的估算**（LRC 只有行级时间）。快段会差半拍。真逐字数据在 MFA 的 `words` 层里，`align_lrc.py` 第 212 行读的就是它，只是后面被 `group()` 压成了行级——接上大约 10 分钟。

## 六、选型建议

| 画面调性 | 推荐 |
|---|---|
| 明亮日系（白墙、白衬衫） | **5 ink** 主歌 + **6 huge** 副歌（红字压得住亮画面）；1–4 的白字靠粗黑边硬撑，只好看不好用 |
| 暗调工业 / 舞台 / 夜景 | **2 slam** 或 **6 huge**；**10 mirror** 这条才成立 |
| 走心慢歌 | **9 blur** 或 **8 type** 主歌，**4 fadeup** 副歌 |
| 古风 / 诗 | **7 vtext** + **5 ink** |
| 长篇不疲劳 | 主歌 5，副歌换 2 或 6，切 3–4 次就够，全程一种会看腻 |
